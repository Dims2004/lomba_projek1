# ReSchedule Studio (demo)
Web self-service untuk Dynamic Optimization & Real-Time Scheduling (API rescheduling berlangganan).

Jalankan:
    pip install -r requirements.txt
    python app.py
Buka http://127.0.0.1:5000  (tutorial muncul otomatis; tombol "Tutorial" di kanan atas).

File: app.py (rute API) | engine.py (solver, validasi, pricing, benchmark) | static/index.html, style.css, app.js (UI)
Catatan: akun, pembayaran, dan kredensial bersifat simulasi (disimpan di memori server).
